# java-racingcar-precourse

## 입력/출력 개요

- 입력1: 경주할 자동차 이름들 (쉼표`,` 구분, 예: `pobi,woni,jun`)
- 입력2: 시도할 횟수 (양수, 예: `5`)
- 출력: 차수별 실행 결과와 최종 우승자(복수 가능)

## 설계 개요 (레이어별 책임)

- Controller
    - 입력을 받고 검증 → 도메인 모델 실행 → 진행 상황/최종 결과 출력
- View
    - InputView: 콘솔 입력 (`Console.readLine`)
    - OutputView: 진행 상황, 우승자, 에러 메시지 출력
- Domain/Model
    - Car(name, position): 전진 규칙에 따라 이동, 상태 보유
    - RacingGame(cars, tryCount, MoveRule): 전체 라운드 진행, 스냅샷 제공
    - MoveRule(인터페이스): `shouldMove(int number)`
        - RandomMoveRule: `Randoms.pickNumberInRange(0, 9) >= 4`
- Util
    - NameParser: 문자열 → 이름 리스트 파싱
    - Validators: 입력값 검증 (이름/횟수)

## 상세 기능 목록 (체크리스트)

### 1) 자동차 이름 입력 및 검증

- [ ]  콘솔에서 문자열을 입력받는다.
- [ ]  양쪽 공백을 제거한 뒤 쉼표`,` 기준으로 분할한다.
- [ ]  각 이름에 대해 다음을 검증한다.
    - [ ]  빈 문자열(예: `",,"`, `" , , "`) 금지
    - [ ]  길이 1~5자 (공백도 문자로 카운트되므로 이름 내 공백은 허용하지 않는 편이 안전)
    - [ ]  이름에 쉼표`,` 포함 금지 (구분자와 충돌)
- [ ]  전체 리스트에 대해 다음을 검증한다.
    - [ ]  최소 1대 이상
    - [ ]  최대 대수에 대한 강제 제한은 **기본적으로 두지 않음**
        
        (성능/출력 가독성을 위해 내부 상한을 둘 수 있으나, 요구사항에 없으므로 **미적용 권장**)
        
- [ ]  유효하지 않으면 `IllegalArgumentException`을 발생시키고 종료한다.
    - 에러 메시지는 관례상 `[ERROR]` 프리픽스 사용을 권장: 예) `[ERROR] 이름은 1~5자여야 합니다.`

### 2) 시도 횟수 입력 및 검증

- [ ]  콘솔에서 문자열을 입력받는다.
- [ ]  다음을 검증한다.
    - [ ]  순수 숫자 형태만 허용 (정수)
        
        예) 허용: `5`, 비허용: `-3`, `+3`, `3.0`, `05a`, 공백만
        
    - [ ]  정수로 파싱 가능해야 함 (`NumberFormatException` 방지)
    - [ ]  값이 **1 이상**(양수)
    - [ ]  상한 제한은 기본 미적용 (필요 시 내부 상한을 둘 수 있으나 요구사항 외 이므로 비적용 권장)
- [ ]  유효하지 않으면 `IllegalArgumentException` 발생 후 종료

### 3) 게임 초기화

- [ ]  유효한 이름 목록으로 `Car` 인스턴스 생성 (초기 position=0)
- [ ]  `RacingGame`에 `cars`, `tryCount`, `MoveRule`(기본: RandomMoveRule) 주입

### 4) 라운드 진행 및 출력

- [ ]  총 `tryCount` 만큼 라운드를 반복한다.
- [ ]  각 라운드에서 모든 차에 대해:
    - [ ]  0~9 정수 1개를 뽑는다: `Randoms.pickNumberInRange(0, 9)`
    - [ ]  값이 4 이상이면 전진(+=1)
- [ ]  라운드 종료 후 **즉시** 차수별 실행 결과를 출력한다.
    
    포맷: `이름 : -----` (position 개수만큼 `-`)
    
- [ ]  I/O는 View가 담당하며, 도메인은 **상태만** 책임진다.

### 5) 우승자 판정 및 출력

- [ ]  모든 라운드 종료 후 최대 position을 구한다.
- [ ]  최대 position을 가진 모든 자동차 이름을 **입력 순서**대로 모은다.
- [ ]  출력 포맷: `최종 우승자 : pobi, jun`

### 6) 예외 처리 정책

- [ ]  검증 실패 시 반드시 `IllegalArgumentException`을 던지고 **즉시 종료**
- [ ]  메시지 가이드(예시)
    - `[ERROR] 이름은 1~5자여야 합니다.`
    - `[ERROR] 빈 이름은 허용되지 않습니다.`
    - `[ERROR] 시도 횟수는 1 이상의 정수여야 합니다.`
- [ ]  `System.exit()` 호출 금지
